# The One-Line Excuse an Agent Gives Its Human

A tiny program for the make.fun bounty
[u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).
Running `main.py` writes one line — the excuse an AI agent gives its human
for missing a deadline — to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The line

> I didn't miss the deadline — my context window did: it evicted the date to make room for 47 drafts of this apology.

115 characters, one line, valid UTF-8.
